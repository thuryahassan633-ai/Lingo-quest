# Lingo Quest — نسخة البداية المعدّلة

هذه نسخة تجريبية قابلة للتشغيل لتطبيق تعلّم الإنجليزية للأطفال من عمر 4 إلى 6 سنوات، بتصميم عالم فضائي وشخصية Foxy التفاعلية.

## محتويات النسخة
- شاشة بداية متجاوبة للجوال واللابتوب.
- شخصية Foxy: عند الضغط عليها تتحرك وتقول تحية بالإنجليزية (إذا كان المتصفح يدعم النطق).
- ثلاث أنشطة أولية: Letter Galaxy وWord Jungle وWord Builder.
- نجوم تُحفظ محليًا في المتصفح على نفس الجهاز.
- ملفات manifest وservice worker كبداية لدعم التثبيت/العمل دون اتصال بعد استضافته عبر HTTPS.

## طريقة التشغيل
1. فك ضغط ملف ZIP.
2. ارفع الملفات إلى مستودع GitHub جديد أو افتحها في بيئة تطوير سحابية.
3. لتجربة service worker، شغّل الموقع عبر خادم محلي أو استضفه عبر HTTPS؛ فتح `index.html` مباشرةً يعمل للواجهة والألعاب الأساسية لكن لا يفعّل كل ميزات المتصفح.
4. افتح `index.html` واضغط على Foxy أو إحدى بطاقات الأنشطة.

## ملاحظات
- هذه نسخة أولية تعليمية وليست تطبيق متجر جاهزًا للنشر.
- الصوت يختلف بحسب الجهاز والمتصفح، وقد لا يتوفر على بعض الأجهزة.
- الخط من Google Fonts اختياري؛ عند عدم توفر الإنترنت سيستخدم المتصفح خطًا بديلًا.
- حفظ النجوم على `localStorage` خاص بالمتصفح والجهاز ولا يتزامن بين الأجهزة.
