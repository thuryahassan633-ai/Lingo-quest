# Lingo Quest — نسخة المغامرات

## الصفحات
- `index.html`: واجهة الترحيب الأولى وزر اللعب.
- `world.html`: خريطة العوالم: الحروف، الأرقام، تركيب الكلمات، الكلمات المصورة، والأناشيد.
- `letters.html`: 26 حرفًا مع مثال واختبار تمييز صوتي.
- `builder.html`: الضغط على حروف الكلمات ثم سماع الكلمة كاملة.
- `vocabulary.html`: صورة، نطق الكلمة، تهجئتها، واختيار الكتابة الصحيحة.
- `numbers.html`: الأرقام من 1 إلى 10.
- `songs.html`: أناشيد منطوقة بإيقاع بسيط باستخدام صوت الجهاز.
- `style.css`: التصميم المتجاوب.
- `app.js`: التفاعلات والصوت والنجوم.
- `data/`: بيانات أمثلة إضافية.

## الرفع إلى GitHub
ارفع محتويات المجلد إلى جذر المستودع (root) بحيث يظهر `index.html` في جذر المستودع. لا ترفع ملف ZIP فقط.

## ملاحظات مهمة
- الصوت يستخدم SpeechSynthesis في المتصفح؛ جودة نطق الأصوات المفردة تختلف بين الأجهزة. للحصول على تعليم صوتي دقيق، نوصي لاحقًا بإضافة تسجيلات بشرية للحروف والأصوات.
- اختبار الحروف يقيس تمييز الصوت من خيارات، ولا يحلل نطق الطفل عبر الميكروفون.
- الموسيقى هنا أناشيد منطوقة آليًا، وليست ملفات غنائية مسجلة.
- النجوم تحفظ محليًا على نفس المتصفح والجهاز.
- بيانات `data/digraphs.json` أمثلة للحروف الثنائية؛ الشاشة التعليمية الخاصة بها تحتاج مرحلة تطوير لاحقة.
